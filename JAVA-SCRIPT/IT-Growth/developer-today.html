02 — DEVELOPER TODAY

What Does a Developer Do Today?

Software development is much more than writing code. Developers solve problems and turn requirements into working software.

THE DEVELOPMENT PROCESS

A Developer's Work

01

Understand Requirements

Understand what users and businesses actually need.

02

Plan

Decide architecture, technologies, data flow and implementation approach.

03

Design

Design interfaces, systems, APIs and database structures.

04

Code

Write and integrate the software needed to solve the problem.

05

Test

Find bugs and verify that the application behaves correctly.

06

Deploy

Release the software and make it available to users.

07

Maintain

Fix issues, improve performance and add new features.

08

Collaborate

Work with designers, testers, product teams, managers and other developers.
