Difference Between var, let, and const

1. Scope

Scope defines where a variable can be accessed in a program.

var Function Scope

A var variable is accessible throughout the function in which it is declared.

It does not follow block scope.

let Block Scope

A let variable can only be accessed inside the block { } where it is declared.

const Block Scope

A const variable is also accessible only within the block where it is declared.

2 .Redeclaration

var Redeclaration is allowed.

let Redeclaration is not allowed.

const Redeclaration is not allowed.

This makes let and const safer because they prevent accidental duplicate declarations.

3. Reassignment

Reassignment means changing the value of an already declared variable.

var Reassignment is allowed.

let Reassignment is allowed.

const Reassignment is not allowed.

A const variable must be assigned a value when it is declared.

4. Hoisting

Hoisting is JavaScript's behavior of processing declarations before executing the code.

var is hoisted and initialized with undefined.

let is hoisted but is not initialized until the declaration is reached during execution.

const is also hoisted but is not initialized until the declaration is reached.

Therefore, accessing a var variable before its declaration results in undefined, while accessing let or const before their declaration results in a ReferenceError.

5. Temporal Dead Zone (TDZ)

The Temporal Dead Zone (TDZ) is the period between entering the scope of a let or const variable and reaching its declaration.

During this period, the variable cannot be accessed.

var Does not have a TDZ.

let Has a TDZ.

const Has a TDZ.
